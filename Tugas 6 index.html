Slide 2

Pengantar Generic

Apa itu Generic? Fitur untuk membuat kode yang bekerja dengan berbagai tipe data. Analog: Kotak penyimpanan yang bisa menampung apa saja, tapi dengan label tipe.

Manfaat:

  • Type safety (keamanan tipe)
  • Code reusability (penggunaan ulang)
  • Compile-time checking
Slide 3

Masalah Tanpa Generic

class Box { dynamic data; // Bisa apa saja Box(this.data); } void main() { var box = Box(Hello); int value = box.data; // Runtime error jika bukan int // Tidak aman! }

Tanpa generic, pengembang sering menggunakan dynamic agar kotak bisa menampung nilai apapun. Konsekuensinya, kesalahan tipe baru diketahui saat program berjalan (runtime error), bukan saat kompilasi.

Slide 4

Solusi dengan Generic

class Box<T> { T data; Box(this.data); } void main() { var intBox = Box<int>(42); int value = intBox.data; // Aman, terjamin int }

Dengan menambahkan parameter tipe <T> pada kelas Box, compiler tahu tipe data apa yang akan disimpan.

Slide 5

contoh Sintaks Generic pada class dan function

class MyClass<T> { T data; MyClass(this.data); T getData() { return data; } } T myFunc<T>(T value) { return value; } void main() { var myIntClass = MyClass<int>(10); var myStringClass = MyClass<String>("test"); print(myIntClass.getData()); // Output: 10 print(myStringClass.getData()); // Output: test var intValue = myFunc<int>(100); var stringValue = myFunc<String>("hello"); print(intValue); // Output: 100 print(stringValue); // Output: hello }

Parameter tipe <T> berfungsi sebagai placeholder yang digantikan dengan tipe konkret saat kelas atau fungsi digunakan.

Slide 6

contoh Kelas Box<T>

class Box<T> { T? _value; Box(this._value); T? get value => _value; void setValue(T value) { _value = value; } } void main() { var intBox = Box<int>(10); print('Int Box Value: ${intBox.value}'); intBox.setValue(20); print('Int Box Value After Set: ${intBox.value}'); var stringBox = Box<String>('Hello, Generic!'); print('String Box Value: ${stringBox.value}'); stringBox.setValue('Hello World'); print('String Box Value After Set: ${stringBox.value}'); var doubleBox = Box<double>(3.14); print('Double Box Value: ${doubleBox.value}'); }

Kelas Box<T> menyimpan data bertipe T tanpa peduli apakah itu integer, string, atau double.

Slide 7

contoh Kelas Pair<K, V>

Generic dengan dua parameter tipe Pair<K, V> memungkinkan penyimpanan dua tipe berbeda dalam satu struktur data.

Keamanan Tipe yang Lebih Baik

Memastikan bahwa kode hanya bekerja dengan tipe data yang kompatibel.

Peningkatan Keterbacaan Kode

Membuat kode lebih jelas dan mudah dibaca.

Memungkinkan Penggunaan Method dari Tipe Data Tertentu

Memungkinkan memanggil method yang spesifik.

Mencegah Penggunaan Tipe Data yang Tidak Sesuai

Mencegah tipe data yang tidak sesuai.

Membantu dalam Desain dan Implementasi

Merancang kelas dan fungsi generic lebih terstruktur.

Slide 14

Generic vs Dynamic vs Object

AspectGeneric<T>dynamicObject
Type SafetyCompile-timeRuntimeCompile-time
FlexibilityTerbatas (sesuai T)Sangat fleksibelTerbatas
PerformanceOptimalOverheadOptimal
CastingTidak perluTidak perluPerlu casting
// Contoh perbedaan Box<int> box1 = Box<int>(42); // Generic: aman dynamic box2 = 42; // Dynamic: tidak aman Object box3 = 42; // Object: perlu casting

Generic<T> unggul dalam keamanan tipe dan performa. dynamic fleksibel tapi tidak aman. Object aman namun perlu casting.

Cache adalah penyimpanan sementara berbasis kunci-nilai. Dengan generic, satu kelas Cache dapat menyimpan berbagai tipe data.

Ringkasan & Latihan
